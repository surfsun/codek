# Node.js 项目开发入门教程 (普通项目版)

## 🚀 什么是 Node.js？
Node.js 是一个基于 Chrome V8 JavaScript 引擎构建的、用于执行 JavaScript 的运行时环境。它允许开发者使用 JavaScript 来编写后端（服务器端）代码，而不仅仅局限于前端浏览器。Node.js 最核心的特点是其**非阻塞 I/O 模型**和**事件驱动架构**，这使其非常适合处理高并发的网络应用，但它也可以用于构建任何类型的命令行工具或后台服务。

## 🛠️ 第一步：环境准备
1. **安装 Node.js**: 请从 [nodejs.org](https://nodejs.org/) 下载并安装最新稳定版本的 Node.js。安装包中会包含 npm (Node Package Manager)。
2. **创建项目目录**: 在你的工作目录下创建一个新文件夹，并进入该目录：
   ```bash
   mkdir my-node-project
   cd my-node-project
   ```
3. **初始化项目**: 使用 npm 初始化项目，这将生成一个 `package.json` 文件来管理项目的元数据和依赖。
   ```bash
   npm init -y
   ```

## 💡 第二步：核心概念——异步编程
由于 Node.js 是单线程的，为了不阻塞主线程（即等待耗时的 I/O 操作完成），它大量使用了异步编程模型。理解这一点至关重要！

* **回调函数 (Callbacks)**: 最早的方式，但容易导致“回调地狱”。
* **Promises**: 解决了回调地狱问题，提供了一种更清晰的链式调用方式 (`.then().catch()`)。
* **Async/Await**: 基于 Promises 的语法糖，让异步代码看起来和同步代码一样直观易读，是目前推荐的最佳实践。

**示例 (使用 async/await):**
```javascript
async function fetchData(url) {
    try {
        // 模拟网络请求或文件读取的异步操作
        console.log(`正在尝试获取数据: ${url}`);
        await new Promise(resolve => setTimeout(resolve, 1000)); // 模拟延迟
        return { data: `成功从 ${url} 获取到假数据` };
    } catch (error) {
        console.error("操作失败:", error);
    }
}

// 调用函数
fetchData('https://api.example.com/data');
```

## 📁 第三步：构建一个简单的命令行工具（CLI）
对于普通项目，我们通常会编写一个执行特定任务的脚本。这里以创建一个读取并处理本地文件的简单 CLI 工具为例。

1. **创建脚本文件 (processFile.js)**: 在你的项目根目录下创建 `processFile.js` 文件，并写入以下代码：
   ```javascript
   const fs = require('fs');
   const path = require('path');

   /**
    * 读取指定文件的内容，并打印处理结果。
    * @param {string} filePath - 要读取的文件的路径。
    */
   function processFile(filePath) {
       console.log(`\n--- 🚀 开始执行文件处理任务 ---`);
       const absolutePath = path.resolve(filePath);

       fs.readFile(absolutePath, 'utf8', (err, data) => {
           if (err) {
               console.error("❌ 错误：无法读取文件。请检查路径是否正确，以及文件是否存在。", err.message);
               return;
           }

           // 模拟处理逻辑：计算字符数和单词数
           const charCount = data.length;
           const wordCount = data.trim().split(/\s+/).filter(Boolean).length;

           console.log("✅ 文件读取成功！");
           console.log(`   原始文件路径: ${absolutePath}`);
           console.log(`   内容字符数: ${charCount} 个`);
           console.log(`   单词数量: ${wordCount} 个`);
       });
   }

   // 假设我们希望处理当前目录下的 test.txt 文件
   const targetFile = 'test.txt';
   processFile(targetFile);
   ```
2. **运行项目**: 在终端中，直接使用 `node` 命令来执行这个脚本。
   ```bash
   node processFile.js
   ```

## ✨ 总结与下一步学习方向
普通 Node.js 项目的开发流程通常是：**编写核心逻辑 -> 使用 `node <script>.js` 执行 -> 通过命令行参数或文件系统进行输入/输出处理**。

你可以继续深入学习以下领域：
1. **CLI 参数解析**: 使用 `yargs` 或内置 `process.argv` 来优雅地接收和处理用户在命令行输入的参数。
2. **模块化设计**: 将不同的功能拆分成独立的模块（例如，一个文件负责读取，另一个文件负责计算）。
3. **错误处理**: 完善 try...catch 和 Promise 的链式错误处理机制，确保程序健壮性。

祝你在 Node.js 的开发之旅中取得成功！
